About this badge

From SAS: The earner of this badge has demonstrated proficiency in using SAS SQL for data processing. They can query, subset, summarize, and present data, as well as combine tables using joins and set operators. Additionally, they can create and modify tables and views, generate macro variables with PROC SQL, and access DBMS data using SAS/ACCESS technology.

What it covers

  • Querying, subsetting, summarizing and presenting data with PROC SQL
  • Combining tables with joins and set operators
